# 知识库问答标准答案与回归题集

## 一、用途

本文件保存“问问智算”知识库问答的人工确认答案，用于判断后续检索、提示词、大模型或知识资料调整后，回答是否仍然正确。

验收采用“关键事实一致”原则，不要求大模型逐字复现本文件。每道题同时维护简单检索题和必要的复杂约束题；普通使用与现场演示优先使用简单题，复杂题主要用于验证格式、边界和抗干扰能力。

机器可读规则位于 `backend/tests/fixtures/knowledge_qa_regression_cases.json`，运行命令：

```powershell
python tools/check_knowledge_qa_answers.py
```

## 五、维护规则

1. 新增标准题前必须先核对真实资料和当前项目规则，不能把一次模型回答直接当成标准答案。
2. 每个核心业务规则至少保留一道简单检索题；只有确有必要时才增加复杂格式约束题。
3. 标准答案记录必须区分正式依据、项目规则、历史样表和已确认记忆。
4. 模型措辞可以变化，但关键数值、适用对象、来源层级、冲突说明和人工复核边界不得变化。
5. 规则或正式资料更新后，同步更新本文件和机器可读回归规则。
