## 第一章 总 则

## 一、为合理确定和有效控制国家石油天然气管网集团有限公司（以下简称国家管网集团）数字与

信息化项目投资，规范可行性研究投资估算的编制，保证投资估算编制质量和深度，根据国家有关法律法规和国家管网集团相关规定，结合国家管网集团数字与信息化项目特点，编制国家管网集团《数字与信息化项目投资计价依据》（以下简称本计价依据）。本计价依据规定了数字与信息化项目投资估算的编制方法、编制内容、编制深度和表现形式，制定了相关费用的计价依据和标准。

## 二、国家管网集团数字与信息化项目投资估算编制按本计价依据执行，详细设计、竣工结算阶段

的造价文件编制参照本计价依据执行。数字与信息化项目中，机房改造、自动化设备接口改造、终端设备等配套设施建设所产生的费用，其设备购置费、安装工程费和建筑工程费应执行国家管网集团《建设项目可行性研究投资估算编制细则》，其他费用及相关费用执行国家管网集团《建设项目其他费用及相关费用计价依据》。

## 三、数字与信息化项目投资估算是指在投资决策阶段，根据数字与信息化项目建设的规模、技术

方案及进度计划等，估算拟建项目的总资金投入，投资估算编制应依据充分、内容全面、数据准确，投资水平合理。

## 四、投资估算、招标控制价、竣工结决算等造价文件应按照价税分离原则编制，均采用不含增值

税的价格和费用，单独计列增值税。

## 五、数字与信息化项目总投资是项目从筹建到竣工验收、交付使用所需的全部资金，不包含运行

维护费用。

## 六、软件开发费用应以可行性研究报告中需求分析所确定的功能点进行计算

## 七、数字与信息化项目工程建设其他费用除国家、地方政府及集团公司有新规定外，原则上不增

加新的费用项目，建设项目因实际情况需要而增加费用项目，应取得国家管网集团投资造价主管部门批准。

## 一、工程费用

工程费用包括硬件费用、软件购置与开发费用、实施费用。

## （一） 硬件费用

## 1. 费用内容

硬件费用包括硬件设备购置费与资源租赁费。硬件设备购置费是指因项目建设所需而购买各类硬件设备所发生的费用，包括服务器类、存储类、网络类、安全类等硬件设备费用，费用包含设备价格及相应的安装调试费、材料费、运杂费等。资源租赁费是指项目建设期根据项目建设所需而租赁硬件、云服务、云平台等资源所发生的费用。

## 2. 计算方法

硬件设备购置费与资源租赁费，采用以下方式综合确定价格：（1）参考国家、行业或地区公布的信息类产品指导价格；（2）同类工程历史采购价；（3）市场询价。编制表格详见附表2。

## （二） 软件购置与开发费用

## 1. 费用内容

软件购置与开发费用包括软件购置费与软件开发费。（1）软件购置费：指项目实施过程中购置应用软件、数据库和需额外购买的系统软件等费用。费用中还应包括软件许可证购置费用、厂商培训费用以及建设期维护费用等。（2）软件开发费：指因成熟软件功能无法满足业务需求，需要在成熟软件基础上新增、改造，或为达成项目目标而进行新软件开发工作所发生的费用。软件开发费包括从软件开发项目委托开发开始到项目完成验收之间所涉及的需求分析、详细设计、系统开发与测试（含基于测试结果，供应商完成系统优化）、验收交付及相关的项目管理支持活动。

## 2. 计算方法

软件购置费，采用以下方式综合确定价格：（1）参考国家、行业或地区公布的信息类产品指导价格；（2）同类工程历史采购价；（3）市场询价。编制表格详见附表3。软件开发费应采用功能点法，包括预估功能点法、估算功能点法，按软件开发功能点计算模板（附表9），以功能需求为依据，进行规模计算、工作量计算和费用计算（附表10）。软件开发费用计价方法及标准详见第三章。

## （三） 采购管理费

采购管理费是指经批准由北京智网数科技术有限公司开展的数字与信息化建设项目采购管理工作收取的费用，包括组织招标、签订合同、接收、验收、保管、发放、催交催运、质量检验等。采购管理费以项目软硬件设备购置金额为基数（不包括软件开发费），计算规则如下：可研阶段，采购管理费包含在软硬件设备购置费中，按不超过购置费（不含增值税）的10%计取，在投资估算中不单独计列；结算阶段，软硬件设备购置费据实结算，采购管理费按实际采购金额乘以对应费率进行结算。

## 一、软件开发费用构成

软件开发包括从软件开发项目委托开发开始到项目完成验收之间所涉及的需求分析、详细设计、系统开发与测试（含基于测试结果，供应商完成系统优化）、验收交付及相关项目管理支持活动。软件开发费用包括软件开发过程中的所有直接成本、间接成本，并考虑开发商的合理毛利润。费用构成如图1所示。<!-- image-->图1软件开发费用构成

## （一） 直接人力成本

直接人力成本包括开发方项目组成员的工资、奖金和福利等人力资源费用。其中，项目组成员包括参与该项目开发过程的所有开发或支持人员，如项目经理、需求分析人员、设计人员、开发人员、测试人员、部署人员、用户文档编写人员、质量保证人员和配置管理人员等。

## （二） 直接非人力成本

直接非人力成本包括：

1. 办公费，即开发方为开发此项目而产生的行政办公费用，如办公用品、通讯、邮寄、印刷和会议等；

2. 差旅费，即开发方为开发此项目而产生的差旅费用，如交通、住宿和差旅补贴等；

3. 开发培训费，即开发方为开发此项目而安排的培训产生的费用；

4. 业务费，即开发方为完成此项目开发工作所需辅助活动产生的费用，如招待费、评审费和验收费等；

5. 采购费，即开发方为开发此项目而需特殊采购专用资产或服务的费用，如专用设备费、专用软件费、技术协作费和专利费等；按附表10列项，不发生不计取；

6. 其他，即未在以上项目列出但却是开发方为开发此项目所需花费的费用；按项目实际在附表10中列项，不发生不计取。

## （三） 间接人力成本

指开发方服务于开发管理整体需求的非项目组人员的人力资源费用分摊。包括开发部门经理、项目管理办公室人员、工程过程组人员、产品规划人员、组织级质量保证人员、组织级配置管理人员、商务采购人员和IT支持人员等的工资、奖金和福利等的分摊。

## （四） 间接非人力成本

指开发方不为开发某个特定项目而产生，但服务于整体开发活动的非人力成本分摊。包括：开发方开发场地房租、水电和物业，开发人员日常办公费用分摊，战略、市场宣传推广、品牌建设、知识产权专利等费用分摊，各种开发办公设备的租赁、维修、折旧分摊以及安全生产费等。

## （五） 毛利润

指开发方直接成本和间接成本之外，应承担的各种税费及税后净利润。

## （一） 软件规模计算

在规模计算前，应根据项目范围明确系统边界，编制人员应根据已确定的系统边界和需求描述，计算软件规模。软件规模计算应采用功能点法， 单位是功能点（Function Point，简写 FP），该方法从用户角度即业务视角计算软件规模。

## 1. 识别功能点计数项

功能点计数项分为数据功能和事务功能两类，其中数据功能包括：内部逻辑文件（ILF）、外部逻辑文件（ELF）；事务功能包括：外部输入（EI）、外部输出（EO）、外部查询（EQ）。数据功能，是系统提供给用户的满足产品内部和外部数据需求的功能，体现系统管理或使用哪些业务数据（业务对象）。ILF或 ELF所指的“文件”不是传统数据处理意义上的文件，而是指一组用户可识别的、逻辑上相互关联的数据或者控制信息。这些文件和物理上的数据集合（如数据库表）没有必然的对应关系。事务功能，是系统提供给用户处理数据的功能，体现系统如何处理和使用哪些业务数据（业务对象）。事务功能又称为基本过程，是用户可识别的，业务上的一组原子操作。（1）内部逻辑文件（Internal Logical File，ILF，又称内部数据）：是一组用户可识别的在系统边界内且被系统维护的逻辑相关数据或者控制信息。（2）外部逻辑文件（External Logical File，ELF，又称外部数据）：是一组从用户角度来看的永久数据，由一个系统使用，但由另一个系统维护。识别 ILF、ELF的步骤如下：① 识别业务对象。业务对象应是用户可理解和识别的，包括业务数据或业务规则。为程序处理而维护的数据属于编码数据，所有的编码数据均不应识别为逻辑文件，与之相关的操作也不应识别为基本过程。② 确定逻辑文件数量。根据业务上的逻辑差异及从属关系确定逻辑文件的数量。③ 是否为 ILF或 ELF。确定该逻辑文件是否在本系统内进行维护，如果是，记为 ILF，否则为 ELF。（3）外部输入（External Input，EI）：处理或控制来自系统边界之外的数据或信息的基本过程。目的是维护一个或多个 ILF或者改变系统行为。EI的基本识别规则如下：① 应是来自系统边界之外的输入数据或控制信息；② 穿过系统边界的数据应是改变系统行为的控制信息或者应至少维护一个 ILF；③ EI不应被重复计数。任何被分别计数的两个 EI至少满足下面一个条件（否则应视为同一 EI）：涉及的 ILF或 ELF不同；涉及的数据元素不同；处理逻辑不同。（4）外部输出（External Output，EO）：向系统边界之外发送数据或控制信息的基本过程，包括外部查询之外的额外处理逻辑。EO的基本识别规则如下：将数据或控制信息发送出系统边界；② 处理逻辑应至少符合以下一种情况：包含至少一个数学公式或计算过程；产生衍生数据；维护至少一个 ILF；改变系统行为；③ EO不应被重复计数。任何被分别计数的两个 EO至少满足下面一个条件（否则应视为同一EO）：涉及的ILF或ELF不同；涉及的数据元素不同；处理逻辑不同。（5）外部查询（External Query，EQ）：向系统边界之外发送数据或控制信息的基本过程。EQ的基本识别规则如下：将数据或控制信息发送出系统边界；② 处理逻辑可包含筛选、分组或排序；③ 处理逻辑不应包含：数学公式或计算过程；产生衍生数据；维护ILF；改变系统行为；④ EQ不应被重复计数。任何被分别计数的两个 EQ至少满足下面一个条件（否则应视为同一 EQ）：涉及的 ILF或 ELF不同；涉及的数据元素不同；处理逻辑不同。表1功能点识别要点<table><tr><td rowspan=1 colspan=2>功能点计数项的分类</td><td rowspan=1 colspan=1>识别要点</td></tr><tr><td rowspan=2 ## 2. 计算未调整的功能点数

## （1）预估功能点法

在需求较为模糊或需求不明确的情况下，可采用预估功能点法，计算未调整功能点数，计算方法如下：$$ _ { \mathrm { U F P = 3 5 \times I L F + 1 5 \times E L F } } $$式中：UFP—未调整功能点数，单位为功能点（FP）；ILF—内部逻辑文件数量，单位为个；35—内部逻辑文件功能点数分配常量；ELF—外部逻辑文件数量，单位为个；15—外部逻辑文件功能点数分配常量。

## （2）估算功能点法

在需求较清晰的情况下，应采用估算功能点法，计算未调整功能点数，计算方法如下：$$ \mathrm { U F P = 1 0 } { \times } \mathrm { I L F } + 7 { \times } \mathrm { E L F } + 4 { \times } \mathrm { E I } + 5 { \times } \mathrm { E O } + 4 { \times } \mathrm { E Q } $$式中：UFP—未调整功能点数，单位为功能点（FP）；ILF —内部逻辑文件数量，单位为个；10—内部逻辑文件功能点数分配常量；ELF—外部逻辑文件数量，单位为个；7—外部逻辑文件功能点数分配常量；EI—外部输入数量，单位为个；4—外部输入功能点数分配常量；EO—外部输出数量，单位为个；5—外部输出功能点数分配常量；EQ—外部查询数量，单位为个；4—外部查询功能点数分配常量。

## （三） 费用计算

在获得了工作量计算结果后，采用以下公式计算费用： $$ \scriptstyle \mathrm { P = A E / H M \times F } $$式中：P—软件开发费用，单位为万元；AE—开发工作量，单位为人时；HM—人月折算系数，单位为人时/人月，按每月22天，每天8小时计算，取值为176；F—人员成本费用单价，单位为万元/人月，取值为4.287万元/人月。人员成本费用单价是指软件开发工作需要的所有成本开销，包括开发方项目组人员人力成本（工资、奖金、福利等）、企业管理费（管理人员工资、办公费、差旅交通费、固定资产使用费、劳动保险和职工福利费、劳动保护费、测试费、工会经费、职工教育经费、财务费及其他组成）、规费（养老保险、失业保险、医疗保险、生育保险、工伤保险、住房公积金）、毛利润和安全生产费。
