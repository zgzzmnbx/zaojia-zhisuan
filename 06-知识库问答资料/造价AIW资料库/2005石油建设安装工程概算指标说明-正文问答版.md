# **总说明**

1. 为了合理确定工程造价和有效控制工程投资，满足石油建设工程计价的需要，特制定《石油建设安装工程概算指标》（以下简称《指标》）。
2. 本《指标》适用于油气田建设工程、石油化工及长距离输送管道建设工程中的新建、改扩建项目。本《指标》是编制工程概算的依据，也可作为编制工程投资估算、招标标底及投标报价的参考依据。
3. 本《指标》与《石油建设工程概（预）算编制办法》、《石油建设引进工程概算编制办法》、《石油建设安装工程费用定额》、《石油建设工程其他费用规定》（[95]中油基字第79号文）配套使用。
4. 编制依据：
1) 国家及行业有关技术标准、施工验收规范和质量评定标准。
2) 国家有关行业、省市标准图和定型图；有关典型工程设计施工图、通用设计图。
3) 正常的地理条件（海拔高度2000m以下）、气候条件和施工环境，正常的施工组织设计，设备、材料、成品、半成品、构件完整无损，符合质量标准和设计要求。
4) 石油计字[2000]第106号颁发《石油建设安装工程预算定额》
5. 指标采用的价格：
1) 本《指标》中的人工按综合考虑，不分工种和技术等级，综合工日的人工单价为每工日23.85元（长距离输送管道土石方工程的工日单价见章说明**：本章人工单价按六类地区综合取定为20.27元/工日，并作为取费基数。高类别地区与六类地区人工工日单价的差额只计取税金并列入工程造价，但不作为计取其他费用的基数。**）。
2) 本《指标》的计价材料采用北京地区2001年价格水平：各地区（单位）编制概算时可按每年“概算指标计价材料地区价差调整系数表”对计价材料进行调整。

# **第七章 刷油、防腐、衬里、绝热工程**

<a id="_Toc264641598"></a>
## **一、本章指标分为：**

第一节 刷油工程：设备管道刷油、金属结构刷油、灰面（布面、玛蹄脂面）刷油、气柜刷油。

第二节 防腐、防火涂料工程。

第三节 手糊玻璃钢工程。

第四节 橡胶板及塑料板衬里工程。

第五节 喷镀（涂）工程。

第六节 衬搪铅工程。

第七节 砖板衬里工程：硅质胶泥衬砖板、树脂胶泥衬砖板、硅质胶泥抹面、耐酸砖板砌体热处理。

第八节 绝热工程：管道绝热、设备绝热、球罐绝热、保护层（防潮层）安装。

第九节 设备专用衬里及龟甲网安装工程。

<a id="_Toc264641599"></a>
## **二、指标包括的内容：**

1．指标中组合了各种管件、阀门、设备人孔、管口部分凹凸等的刷油、防腐、绝热工作内容。

2．刷油指标包括除锈、刷油工作内容。

3．防腐（防火）工程指标包括除锈、喷涂（涂刷）。

4．手糊玻璃钢工程：指标组合内容包括除锈、下料、填料干燥过筛、胶料配制、刮腻子、玻璃丝布脱脂、衬贴玻璃布。

5．橡胶板及塑料板衬里工程：适用于设备、管道、阀门的橡胶衬里和设备内表面软聚氯乙烯板的衬里工程。指标组合内容包括除锈、下料配浆、刷浆贴衬、火花检查、（硫化）、硬度检查。管道衬橡胶和阀门衬橡胶采用设备衬橡胶指标。

6．喷镀（涂）工程指标适用于金属设备管道等表面气喷镀和塑料粉料的喷涂，指标综合除锈、金属丝脱脂、喷镀涂、质量检查。

7．衬搪铅工程指标适用于金属设备表面衬铅、搪铅，指标综合了除锈、清洗、衬铅板、质量检查等。

8．砖板衬里工程指标适用于金属设备的耐酸砖板的衬里，衬砌指标综合了除锈、衬砌、养生、酸洗，胶泥抹面指标综合了除锈、涂稀胶泥、分层抹平、酸洗、钩钉制安、挂铁丝网，耐酸砖板砌体热处理指标包括制作安装电炉、升温、记录、检查。

9．绝热指标包括绝热材料的绑扎（粘结或涂抹），指标不包括绝热材料费，金属油罐绝热分板类和涂抹类两种绝热方式，综合了角钢固定圈的制作安装及型钢材料费。

10．设备专用衬里及龟甲网安装工程中，衬里包括设备内壁除锈、人工涂抹、机械喷涂耐火耐磨浇注料、浇注料振捣、手工捣打、锚固钉及端板除锈（油）和安装、球形拱胎摊销等：龟甲网安装包括龟甲网除锈（油）、龟甲网与器壁、端板焊接。设备专用衬里及龟甲网安装工程指标中包括锚固钉和端板的材料费。

## **三、指标未包括内容：**

1．防腐（火）涂料费用。

2．金属罐防腐绝热的超高增加费；

3．设备专用衬里及龟甲网安装工程指标不包括隔热、耐磨等衬里料和龟甲网的主材费。

<a id="_Toc264641601"></a>
## **四、指标使用方法：**

1．刷油、防腐工程量原则上按其展开面积计算，当不能按展开面积计算时，按金属结构重量以100kg计算。

2．刷油工程中管廊钢结构和钢管塔架按其重量套用相应指标时，应乘以系数0.66；H型钢钢结构按其重量套用相应指标时，应乘以系数0.48；铸铁管刷油套用相应的设备管道刷油指标时，乘以系数1.15；喷漆执行相应的刷油子目。刷油工程指标除带锈底漆为一遍外，其余均按两遍考虑。当设计为一遍时指标乘以系数0.52；若增加一遍时，指标乘以系数1.48。

3．防腐（防火）工程按涂料种类、施工方法、成膜厚度等选用指标子目，管廊、H型钢钢结构按其重量套用相应指标时，应进行调整，调整系数同刷油工程；防腐、防火指标子目中不包含防腐、防火涂料材料费。如设计采用新的防腐材料时，套用相近指标子目。

4．手糊玻璃钢工程指标中玻璃钢均按二底一布二面综合考虑，若玻璃布层数增加，可采用增一布子目，其他不变。环氧呋喃玻璃钢衬里执行环氧酚醛玻璃钢衬里指标，其余玻璃钢执行环氧树脂玻璃钢衬里指标。

5．砖板衬里按胶泥和砖种类选用相应子目，指标中不含胶泥和砖板的材料费，可按各种胶泥的配方和当地预算价格计算。

6．保护层按其结构选用相应子目，除“铝箔－玻璃钢安装”和“抹面材料安装”指标中未包括铝箔－玻璃钢和抹面材料的材料费外，其它均包含材料费。

7．设备专用衬里及龟甲网安装工程适用于催化裂化装置的龟甲网安装和隔热、耐磨衬里工程。

8．金属罐防腐绝热施工高度超过6m时，超高部分以人工和机械各增加15％计算超高费，超高部分工程量分别按罐体防腐及绝热总面积乘以下表的超高比例计算。

# **第十二章 管段防腐、补口补伤**

<a id="_Toc264641624"></a>
## **一、本章指标共分为：**

第一节 管段外防腐：石油沥青防腐、环氧煤沥青防腐、煤焦油瓷漆防腐、聚乙烯夹克防腐、环氧粉末防腐；现场人工石油沥青防腐。

第二节 管段补口补伤：石油沥青补口补伤、环氧煤沥青补口补伤、石油沥青热缠带补口补伤、煤焦油瓷漆缠带补口补伤、聚乙烯热收缩套（带）补口补伤、环氧粉末补口补伤。

<a id="_Toc264641625"></a>
## **二、指标组合内容：**

1．管段防腐：抛光除锈、防腐、质量检验、成品管堆放、编号。

2．补口补伤：开挖作业坑、清理管口、除锈、预热、补口补伤。

<a id="_Toc264641626"></a>
## **三、指标使用方法：**

1．管段外防腐以“1000m<sup>2</sup>”为计量单位，工程量计算公式为：钢管外径×π×（管线设计长度-弯头长度）×1.015；弯头防腐费用另行计算。

2．“混凝土连续覆盖层”、“管沟现浇混凝土稳管”指标中已综合考虑了水泥车调遣费。

3．固定墩、线路标志桩不分规格大小均按“10m<sup>3</sup>”、“10个”计算。

4．线路中的防护工程、涵洞等建筑工程执行工程所在地区有关定额。

5．阀室以“座”为计量单位，包括阀室内的工艺安装工程，使用时按主管径尺寸套用指标。主阀用量与设计要求不同时可以调整，但安装费不作调整。

6．放空管以“处”为计量单位，未包括点火装置，使用时按放空管尺寸套用指标。

7．管段运输中已综合管件及弯管的运输，并综合考虑了水泥或沥青路面、砂石路和土路的因素，使用时按管线实际长度及其规定损耗计算工程量。

8．管段运输基本运距为80km，实际运距不同时，180km以内（含180km）每增减10km机械费增减6.6％；超过180km时，超过部分按公路运输吨公里市场价格计算运输费用。

9．在山区段若采用高架车运输，则采用管段运输指标并按系数调整：人工费×2.22，机械费×1.39，基本运距取定为65km，实际运距不同时，180km以内（含180km）每增减10km机械费增减9.3％；超过180km时，超过部分按公路运输吨公里市场价格计算运输费用。

10．本章指标不论土建和安装工程，均按中油基字[95]第79号文规定取费。
