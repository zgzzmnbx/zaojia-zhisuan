## UI 硬门禁

- [ ] 自托管苹方与 `--dws-*` token。
- [ ] 仅使用 `28 / 20 / 16 / 14 / 13 / 12px`；纯数字技术坐标按规范可用有注释的 `11px`。
- [ ] 无 `9px / 10px` 可见文字，无同层级字体忽大忽小。
- [ ] 白底、1px 边框、6—8px 圆角、无常驻阴影、无渐变、无卡片套娃。
- [ ] 1366 / 1440 / 1920、Dock 窄容器、深浅色、键盘与减少动态效果通过。
- [ ] 所有图形 computed 字体、字号、字重、行高和等宽数字通过。
